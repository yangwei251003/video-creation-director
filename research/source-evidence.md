## 字体与工程核实

字体方向核对原作者项目：Adobe Source Han Sans/Serif、Noto CJK、Smiley Sans、LXGW WenKai；推荐与授权边界见技能 typography.md。实际样片从 google/fonts 官方路径下载 Noto Sans SC / Noto Serif SC，按 Git blob 校验、保留 OFL 文本和 SHA-256，未修改字库。全稿实际字符覆盖另外检查。

Remotion 使用官方本地技能、安装包源码和官方 flickering 文档；原生模板与 Remotion 路线分开，不把 Motion 动画库当视频导出器。测试工程固定 Remotion 4.0.539；现有技能插件说明版本 4.0.534，调用时按真实工程 API 验证。

元宝搜索用于发现线索；关键结论回到公开原仓库、文件、许可、官方文档与实际输出核实。没有将搜索摘要升级为已听已看的视频内容。
