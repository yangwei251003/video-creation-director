# Third-party sources and rights

The MIT licence at the project root covers the original director instructions, original design specification, validation utilities and original design-lab composition. It does not relicense linked templates, software, fonts, images, audio or third-party methods/documents. No current personal MotionGit package, original footage, repository checkout or credentials are included.

- Adu: [adu-motion-video](https://github.com/adunext/adu-motion-video), legacy commit `4a52ae2cff542cfb0bfcf6e93e5120c55d0110cf`, MIT code. Public demonstrations and third-party footage/music have separate restrictions. Thirteen current free MotionGit pages explicitly state MIT code; fifteen gated pages' complete licences remain unverified. The research catalog links sources, it is not a substitute template distribution.
- Vincent: [video-shotcraft](https://github.com/Vincentwei1021/video-shotcraft), Apache-2.0 (audio separately licensed); [mg-styles-15](https://github.com/Vincentwei1021/mg-styles-15), MIT. This project contains original summaries, source indexes and attribution, not a bundled copy of their executable libraries.
- [video-talkcraft](https://github.com/Vincentwei1021/video-talkcraft) and [anything2explainer](https://github.com/Vincentwei1021/anything2explainer): PolyForm Noncommercial 1.0.0 at the reviewed commits. No code or complete skill/template is bundled. Commercial toolkit use requires separate permission under the authors' terms. Linked repositories without licences are not treated as permission to redistribute.
- Noto Sans SC / Noto Serif SC: unmodified official Google Fonts binaries, OFL-1.1. Exact Git blob and SHA-256 are in `examples/design-lab/public/fonts/manifest.json`; original licence files are adjacent to fonts. Copyright/Reserved Font Names remain as in those files. Fonts are not sold separately.
- Remotion and its npm dependencies retain their own licences and applicable use conditions. They are installed from the package registry, locked in package-lock.json and not committed as node_modules. Check [Remotion licensing](https://www.remotion.dev/license) for the organisation and intended use.
- The public Douyin acquisition approach is informed by [vangie/douyin-transcriber](https://github.com/vangie/douyin-transcriber/tree/b397d3e8ab2f85c9955ee0cd199b8f66c0f9b123), MIT, Copyright (c) 2026 BabelCloud. The Python adapter is written for this project with exact-ID checks, bounded downloads and evidence output; the original MIT notice is retained in `skill/references/licenses/douyin-transcriber-MIT.txt`. This does not grant redistribution rights to downloaded videos.
- Optional video analysis uses faster-whisper / CTranslate2, PyAV, RapidOCR, ONNX Runtime and OpenCV. Each dependency and model retains its own licence. Installed packages/model weights are not bundled; the tested compatibility versions are in `skill/scripts/requirements-video-reader.txt`.

Third-party screenshots and sampled videos used for private research are kept outside the public distribution. Preview images and videos in `docs/` are rendered from the original design-lab project, using the bundled OFL fonts.
