# 制作、声音与可重复输出

## 镜头卡

每个镜头记录：叙事作用、真实输入、文字、构图、参考/卡号、参数与适用条件、动作的进场/稳定/退场、声音、转场锚点、失败情形、输出尺寸与时间。先找对应卡与 demo 的真实实现，不凭效果名字复刻。品牌变化使用 token，结构变化有原因再做。

阿杜历史源码进一步提供了可执行合同：选择完整语义组，同时检查对象数量、文字容量、媒体槽位、保护动作窗和前后依赖。九屏需要九份真实素材，作品墙不能用重复图片冒充不同作品；二项构图不能硬塞三项。跨镜头保持对象身份时使用另一个实际镜头；仅在同一次连续展示、不重启源播放时允许局部放大再拉回，不能剪走后复播同段。

将**输出时钟、源动作时钟、全片声音时钟**分开记录：人物/字幕跟输出时间，模板动作按合法源区间映射，声音事件映射到全片。保护动作窗保持原速，额外时间加在允许的阅读稳定段；尾音可能越过镜头边界，独立片尾必须保留或有意淡出。不能整体拉慢模板来塞长文，不能每换模板重启背景音乐。

知识模板还要检查其模型适用域：几何不变量、统计分母、倍率、路径占用释放、观测点、系统边界、有根树与循环区别。将示例科学名词换掉不等于新模型成立。具体历史参数见 [阿杜研究](https://github.com/adunext/adu-motion-video/tree/4a52ae2cff542cfb0bfcf6e93e5120c55d0110cf) 和本技能目录快照。

产品片借鉴 video-shotcraft 的“镜头卡 + 可运行实现 + 常见陷阱”方式；讲解片吸收“旁白先定时、概念逐层展开”的一般方法。依赖包和参考必须分开：公开可阅读不等于可复制或商用。不可移植作者推广语、强制分享/点赞、登录索钥步骤和与用户授权冲突的确认关卡。

## 运动控制

时间以秒设计划，导出时按真实 fps 转帧；每镜头稳定阅读窗口不被转场吃掉。Remotion 属性由 useCurrentFrame/useVideoConfig 求值；Motion/GSAP/HTML 要用实际模板的 seek 协议并验证任意帧重取一致。不要叠加自由播放 CSS animation。素材加载、种子随机、字体完成、蒙版边缘和透明合成先查。

长片先测试最复杂一镜与最密文字；出错只返修相关片段，最终检查整片衔接。保存原输入、参数、依赖 lockfile、字体/资产清单、输出散列。

## 从教程吸收的制作结构

- **长期工程与片段库。** 复用已验证的 Remotion 工程和依赖，不每次重装一套环境；每个动画保持自己的组件、资产、参数和样例，正式成片按具体任务组合。可复用不等于把所有题材做成同一皮肤。
- **先方案，后代码。** 有参考时按实际内容拆解；没有参考时先明确“观众要看懂哪种关系”，提出合适的视觉表达，再准备关键图像/数据。精确物体外观或复杂场景先取得合适图像，再驱动少量有效运动；不要求CSS/SVG逐笔重画所有真实对象。
- **开放创作与精确控制分开。** 探索阶段让模型给合理方案；已经确定的动作暴露为参数，如比例、倾角、透明度、入场时刻、镜头轨迹。修改前存版本，使用当前 Remotion 支持的参数/预览界面调整，不能仅靠多轮含糊自然语言碰运气。
- **手绘分复杂度。** 简单几何与线稿可用SVG路径动画；密集复杂线稿可用遮罩分区显现。遮罩只是绘制观感，不声称它是正确笔顺。关键文字/标注留保护区域，分层/分幕减轻渲染负担。
- **代表性试片。** 短片可先验证约10秒，复杂长片选最有代表性的片段；包含真实文字、主要运动、转场和声音。通过内部检查后继续制作，不把教程里的“等我确认”变为用户直出请求的新增审批门。对失败镜头有界返修，最后复核全片接缝。
- **渲染前冻结外部输入。** 地图路线、API数据、素材和字体先获取/核实/缓存；渲染按本地固定输入逐帧求值。权限或密钥由现有安全配置管理，不写源码/公共仓库，不让每帧请求第三方接口。

以上为对用户指定教程的适配，具体观察范围见项目研究报告。固定1080p/30fps、无旁白、每次变化踩重拍是特定案例选择，不是全题材要求。作者的模型排名、成本和涨粉效果没有本机对照实验，不写成工具保证。

## 声音设计

- 旁白片：实测每段音频时长，字幕对齐实际语音。主题难度决定停顿；不得为迁就模板挤字或强制倍速。
- 音乐片：先找段落与重拍，再安排少量视觉峰值；不是每个元素都有音效。
- 层次：人声主导，音乐自动或手工避让，转场提示与重音只在需要处出现；检查耳机/扬声器及实际导出。
- 逐文件记录声音授权与来源。作者代码开源不代表所有音乐可自由商用；没有授权就用用户素材、合法替代或保持静音。
- loudness/峰值分析是辅助；目标按发布平台与项目指定，不能机械将每片都归一化到某一个响度。没有听到成片不报告“混音合格”。

## 剪映/编辑器

可编辑交付分别验证素材文件、时间线、字体与动画能力。平台/版本不同须实际打开验证；作者曾在 macOS 某版剪映验证，不能证明 Windows 全部可用。必要时交付 Remotion/模板原生工程与明确支持范围。

透明动画需预先约定目标软件、容器/编码与Alpha支持，按[Remotion透明输出官方文档](https://www.remotion.dev/docs/transparent-videos)选择相容设置；仅把背景颜色删掉不等于正确透明成片。将导出叠在明暗底上检查阴影、半透明边缘、黑边和锯齿，并在实际PPT/编辑器中测试；本技能样例没有验证透明导出。精细控制参考[参数化视频官方文档](https://www.remotion.dev/docs/parameterized-rendering)，通过实际版本支持的props/schema/controls驱动，不假设预览界面已有某个自定义控件。

有声片继续读取 [声音导演](sound-direction.md)，所有项目通过 [OpenFilm工作台](openfilm-workbench.md) 组织交付。
