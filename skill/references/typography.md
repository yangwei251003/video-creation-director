# 字体表现力：先让文字成为画面的主体

## 字体角色与替换方向

每片通常使用 1–2 个主字体家族，数字/代码可加专用角色。先决定性格再选字，不用字体数量制造丰富。以下是选型方向，不表示机器已安装或所有字重都存在。

| 方向 | 中文候选与用途 | 搭配与边界 |
|---|---|---|
| 清晰、科技、产品 | 思源黑体 SC / Noto Sans SC | 中粗标题、常规正文；数字对齐；SC 字形不被 JP 文件替代 |
| 文化、编辑、沉静 | 思源宋体 SC / Noto Serif SC | 宋体大标题 + 黑体注解；细横画在手机上须实测，不能一律极细 |
| 年轻、速度、宣言 | 得意黑 Smiley Sans | 窄斜展示字用于短标题；正文另配中性黑体；不虚构不存在的字重轴 |
| 人文、解释、手写 | 霞鹜文楷 / LXGW WenKai | 短引语/批注/教育场景；不用长段手写字体承担高密度数据 |
| 品牌指定 | 已获许可的品牌字体 | 先核对文件、嵌入/再分发范围；不要用系统安装状态证明许可 |
| 英文/数字强调 | 配套西文、衬线或等宽数字 | 检查大小写、数字宽度、标点及中文混排基线；不能只测英文 |

官方来源与许可证以具体 release 为准：[思源黑体](https://github.com/adobe-fonts/source-han-sans)、[思源宋体](https://github.com/adobe-fonts/source-han-serif)、[Noto CJK](https://github.com/notofonts/noto-cjk)、[得意黑](https://github.com/atelier-anchor/smiley-sans)、[霞鹜文楷](https://github.com/lxgw/LxgwWenKai)。这些项目提供 OFL 许可；复制字体文件时保留该文件对应的版权与许可，不单独售卖字体。产品其他字体不因此自动免费。

## 排版顺序

1. 先写观众真正要读的短语，每屏一个主句，关键词有意义地放大；正文不是把整段脚本贴上去。
2. 在真实画幅排版，按语义手动断行。避免孤立一字、标点挂错位置、数字与单位断开。英文、URL、代码按角色处理。
3. 标题/正文/注解建立至少清楚的大小或重量差；注解不因叫“注解”而不可读。1080 宽竖屏可从标题 88–140、正文 42–60、辅助 28–36 px 起步，横屏按实际观看尺寸重定，不机械按画幅宽度等比放大。最终由屏幕观看与文字量验证。
4. 留阅读稳定段。进场未稳定和退场被遮挡的时间不计可读时长。先以实际朗读/目标受众速度估计，再看审；无声片尤其要留足阅读时间。
5. 带字幕/平台按钮的安全区独立于装饰边距；测试 9:16 后不是把 16:9 中间裁走就交付。

## 8 个可复用文字动作配方

以下范围仅是 30 fps 起始建议，使用参考镜头的实测参数优先；以秒记录再换帧。

| 配方 | 设计方法 | 使用/避坑 |
|---|---|---|
| 语义分组揭示 | 2–4 个短语共享基线；蒙版上移 0.3–0.55s，组间延迟 0.08–0.16s | 避免中文逐字无意义弹跳；最终整句稳住 |
| 重音落位 | 关键词 1.06→1，轻下落/短弹性；其他词保持稳定 | 一镜一个重音，不让整屏一起冲击 |
| 描边转实心 | 同一字形轮廓与填充层交接，0.25–0.5s | 描边不可吞细笔画；结束要恢复易读实体 |
| 字重呼吸 | 已验证 `wght` 轴 450→750→650，按剧情强调 | 实测字宽变化/换行；静态字体不能假冒连续插值 |
| 编辑式行幕 | 水平遮罩逐行展开，附一条细分隔线 | 适合衬线与文化；避免扫光盖住文字 |
| 数字翻滚 | 数字列固定宽度，缓出到实际目标，单位静止 | 保留小数/负号/单位；不能用动画伪造统计含义 |
| 路径批注 | 下划线/圈注随讲解绘制，字本身稳定 | 线条不穿过笔画；不把打印字体遮罩称真实笔顺 |
| 匹配字转场 | 上镜末字与下镜主标题共享位置/轮廓/颜色 | 保留方向和视觉锚点，转场前后都可读 |

材质与效果按字体笔画选择：柔和阴影建立分层；窄描边增强复杂背景对比；双色/局部渐变只强调关键词；浮雕/金属/纸墨须与内容匹配。禁止对全部字同时叠加模糊、辉光、描边、色差和震动。最终导出压缩后再查边缘。

## 工程检查

- 把获准使用的字体放入项目资产并记录来源/散列。离线渲染优先本地文件；等待加载，缺失直接报错，不能静默替换后仍声称符合品牌。
- 检查全稿字符覆盖、字体内部 family、实际字重与 `fvar` 轴。对变量字体只写存在的轴。
- 本次环境实查 Noto Sans SC VF 为 wght 100–900，Noto Serif SC VF 为 wght 200–900；LXGW WenKai Regular 无变量轴。它是此机器检查结果，不是对任意同名字体的保证。
- 浏览器 `document.fonts.ready` 之后测量最终盒；检查最密文字和罕见字。Remotion 使用实际版本的本地字体加载 API 和帧驱动属性，避免 CSS animation 导致离线闪烁。
