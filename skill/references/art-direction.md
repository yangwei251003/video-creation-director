# 美术、配色与转场

## 质感来自一致的选择

先建立一个可辨认的方向：字体性格、留白、边缘、材质、光照、镜头运动都说明同一件事。不要把渐变、玻璃、粒子当万能升级。为每镜头画清主体、信息层、环境层和前景遮挡，最多一个主视觉动作；其余层级负责承托。

`assets/design-tokens.json` 包含 6 组原创起点：编辑朱砂、石墨青柠、钴蓝纸白、森林奶油、夜幕珊瑚、展览紫。用背景/文字/强调/弱化色的角色组织，跨镜头保持角色。可用 70/20/10 近似分配面积，但真实品牌与画面优先。高彩度颜色留给关键动作/数据；背景避免饱和度和文字争夺注意。

文字对比用工具检查可作底线提示（一般正文 4.5:1、大字 3:1），仍需在实际背景、运动及压缩后检验；这是借用可访问性参考，不代表视频认证。弱化色不可承担重要小字。不能只靠红/绿区分意义，配形状、标签和位置。

## 六条可实施的质感路线

| 路线 | 具体设计 | 不适合的滥用 |
|---|---|---|
| 编辑与纸墨 | 暖白纸色、深墨、细线网格、大宋体、微弱静态颗粒、页边标注 | 颗粒淹没小字，泛黄滤镜盖住所有素材 |
| 精密产品 | 深石墨、中性面板、单一亮色、真实 UI 裁切与局部放大、克制投影 | 虚构界面和满屏玻璃卡片 |
| 明亮几何 | 大色块、清晰矢量图、尺度反差、轻微弹性与图形匹配切 | 每元素同时弹跳、粗圆角一套到底 |
| 展览与品牌 | 大留白、独立主物、定向柔光、缓慢视差、精细边缘 | 无意义旋转产品导致卖点不可见 |
| 手作与解释 | 矢量批注、笔触线、手写短注、纸片/贴签、内容分步呈现 | 线稿真假混淆、装饰遮挡关系图 |
| 戏剧与叙事 | 明暗焦点、前景遮挡、景深层、方向一致的推拉与声音桥 | 无理由闪白、眩光、抖动、破坏人物连续性 |

## 转场必须回答“为什么切到下一镜”

| 叙事关系 | 转场 | 初始长度 | 连续性检查 |
|---|---|---:|---|
| 同一主体换信息 | Match cut / 共享物体变换 | 0.25–0.65s | 中心/尺度/方向锚点一致 |
| 展开细节 | 推入屏幕/对象遮罩 | 0.4–0.8s | 入场和目标细节可辨；不要仅放大糊图 |
| 因果/流程 | 线条延伸或形状接力 | 0.3–0.6s | 方向表示关系而非随机飞线 |
| 对比/前后 | 分割擦除、滑窗、直接对照切 | 0.25–0.55s | 比较尺度/单位一致、两状态有阅读时间 |
| 章节/观点转折 | 清晰硬切 + 色块/标题 | 0–0.3s | 硬切可优于复杂转场；声音与结构配合 |
| 时间流逝/情绪 | 克制叠化、光线变化、声音桥 | 0.4–1.0s | 重叠文字不冲突；无误导时间线 |
| 高能量音乐节点 | 方向甩镜/短暂运动模糊 | 0.15–0.35s | 仅少数峰值使用；停稳后可读 |

这些是调参起点，不是规定所有镜头秒数。先设计停留，再给过渡时间；避免一整片只有线性淡入。统一 2–3 种语法通常比每镜头换一种更成熟。高频闪烁不是质感捷径。

## 运动与层次

- 区分主动作、跟随动作、稳定段和收尾。位移加减速要跟物体质量/情绪一致；短促标题与沉静展品不能用同一弹簧。
- 参考曲线可从 `cubic-bezier(0.16,1,0.3,1)` 开始，镜头运动平滑进出，物件入场较快停稳；有参考源码就使用其真实参数。
- 视差来自前中后景不同位移，不是所有层缩放；阴影方向、圆角、边线统一。单个镜头用一个明显的空间线索即可。
- 在转场开始/25%/50%/75%/结束检查蒙版、出框、重复内容、文字遮挡和突然黑帧。只看首尾不能证明转场成立。
- 无声片不随意加音；有旁白优先语义节点，音乐片优先拍点但不能牺牲阅读时间。全片不要持续同一强度。
