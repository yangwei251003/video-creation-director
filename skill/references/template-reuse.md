# 来源、模板复用与方法融合

研究日期 2026-10-28。完整清点结果见 `catalogs/`，更详细的方法与观察报告随项目仓库的 `research/` 交付。目录快照不是最新库存，条目数不能当质量证明。

## 三层复用

1. **方向**：观众、情绪、信息关系、品牌适配；可用公开演示学习构图/节奏规律，但不冒称已取得包。
2. **镜头**：精确定位镜头卡、demo、版本/commit 和参数；只移植当前镜头实际需要的实现，保留许可。
3. **成片**：重新组织叙事、真实素材、画幅、字体与声音，按本片验收。整片套模板不是质量保证。

## 参考契约最小内容

```
来源 URL / commit 或包版本 / 许可 / 可获取状态
观察方式与范围（页面、源码、抽帧时间码、连续看审、听审、渲染）
本片用途与匹配理由（题材、观众、画幅、信息密度）
视觉锚点：主体、字体角色、色彩角色、布局比例、材质
运动锚点：入场、停留、退出、曲线、转场连接物、声音落点
保留什么 / 为什么改变什么 / 不适配内容
```

比较通常 2–3 个，不为数量增加流程。用户已经选定时沿用；与内容明显冲突则说明具体风险并给合理调整，不擅自换成另一套。

## 证据等级不混用

目录完整 ≠ 全部源码可读；源码审阅 ≠ 实际执行；抽帧 ≠ 连续运动；有音轨 ≠ 听审；公共 demo 可看 ≠ 包可下载；网络连接 ≠ 宿主工具加载。分别记录。受登录、资格或未开放模板阻碍时，使用合法公开示例推进，留下缺口，不绕过访问限制。
