# 声音导演

## 从参考吸收什么

[浙大猫学长教程](https://www.douyin.com/video/7702007022564183336)将问题分为节奏与音色：先从代码/动作时间取得事件位置，再挑符合物理、材质和情绪的音色。简单 pop 可以合成；复杂质感常适合实录或分层 Foley。UI 声音应先试界面音库，真实点击器录音未必比设计过的 UI 音更合适。人气/下载数只是搜索信号，实际匹配和试听优先。

公开 [vibe-motion/sound](https://github.com/vibe-motion/sound/tree/11e92dc42726c063007b2fe3fb4ecc3415d1eb20) 的当前脚本仅实现 Freesound 搜索及HQ MP3预览下载，README列举的其他库与完整混音不代表免费代码已实现。上游没有代码LICENSE，本技能独立实现公开获取适配，不复制其脚本；不运行其改代理脚本，不购买完整版。私有研究材料和转写不公开。

## 选声与素材

`python scripts/sound_sources.py search "wood click" --out candidates.json` 搜索明确CC0公开音效；`fetch <声音页面URL> --out assets/source` 重新核对许可并下载公开预览，生成作者/许可/散列记录。不读Cookie、不索钥。未知许可不自动放行；CC BY需明确接受并记录完整署名。原件需登录时改用合法可取得资源，不声称预览等于原始WAV。

界面音可从[Kenney Interface Sounds](https://kenney.nl/assets/interface-sounds)官方CC0包选取；环境/物体音按材质、距离、空间、情绪检索。音乐、旁白独立核权。不要用音效库版权推导音乐许可。转MP3为WAV方便处理但不恢复丢失音质。资源检索失败时换已核验来源，不修改用户网络。

## 声音事件与混音

按 `assets/audio-cues.example.json` 建立事件表。每条事件关联 `shot_id` 和动作、`anchor_seconds`、原文件片段、实测 `transient_offset`、增益、淡入淡出、声像、尾音；全局放置起点 = 动作时刻 − (瞬态位置 − 源入点)。源时间不可与输出时间混淆。节奏变更必须复核事件；关键瞬态误差目标≤1帧，但实测误差和设计偏移分开。

旁白、音乐、环境、动作音效分轨。人声优先；音乐在说话处有意避让，保留停顿和动态，不每个动作都加声。音色按一组材质/空间统一，少量强调声制造层次。不要每换镜头重启BGM。尾音可跨镜头，但片尾必须保留或淡出；不要硬截波形。

`audio_mix.py` 以本地FFmpeg输出48kHz PCM分轨和混音，并做峰值/响度分析；按事件表的显式gain envelopes降低配乐。先调分轨平衡，再保护最终峰值；不机械将所有题材归一到固定响度。输出报告不声称听感达标。

OpenFilm `<audio>` 位于film.html，页面本身无声音。优先 Link 与主轨联动，跨多镜头音乐保留全片时间；锁定轨道不会自动跟随。Unlink不一定关闭主轨联动。不要另开watcher重复移动。手动裁切、删除、动画内节奏变化后，读取最新时间线与事件表，再做局部修复和听审。

## 验收

实际导出后检查瞬态落点、爆音、叠音、尾音、人声可懂度、音乐掩蔽和首尾接缝，完整听审后填写时间码观察。测量、ASR、波形和播放成功都不等于听到。没有听审能力时保留 listened_full=false 和未核验，不生成完整质量总分。
