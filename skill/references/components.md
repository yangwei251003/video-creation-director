# 视觉组件：按信息关系挑选

“更丰富”意味着表达更合适，不是每屏加更多东西。每镜头一般一个核心组件，必要时一个证据或注解组件。下列 24 类为原创设计规格，可结合合法镜头卡实现，不承诺均有现成渲染器。

| 类型 | 表达什么 | 设计动作 / 验收 |
|---|---|---|
| 1 宣言标题 | 核心观点 | 语义分组、字级反差；完整阅读停顿 |
| 2 编辑引语 | 情感/观点 | 宋体/引号/出处；引用准确可追溯 |
| 3 数字指标 | 量级变化 | 等宽数字滚动、单位固定；真实值与精度 |
| 4 对照双栏 | 前后/优劣 | 相同基线与尺度；不用视觉面积夸大 |
| 5 证据卡 | 引用/截图 | 时间/来源标签、局部高亮；可核实 |
| 6 真实 UI 聚焦 | 操作/功能 | 遮罩、光标路径、局部放大；不得伪造真实界面 |
| 7 设备/画框 | 环境与场景 | 边框为内容服务；UI 字不能缩到不可读 |
| 8 镜头窗口 | 实拍/B-roll | 内容裁切与遮罩；主体/版权正确 |
| 9 主物展台 | 产品/对象 | 轮廓光/投影/缓慢视差；真实外观 |
| 10 分解图 | 结构/组成 | 组件分层展开；装配/关系不误导 |
| 11 过程时间线 | 阶段/历史 | 一条路线逐项点亮；时间先后正确 |
| 12 因果链 | 机制/推导 | 节点接力、箭头导向；不能把相关当因果 |
| 13 系统拓扑 | 连接/架构 | 先主干后细节；连线去拥挤 |
| 14 等级树 | 分类/归属 | 逐层展开；同层对齐 |
| 15 坐标图 | 趋势/分布 | 轴、单位、时间和来源先可读；不伪造数据 |
| 16 比例条/环 | 占比 | 面积/长度真实；小数与总和正确 |
| 17 矩阵 | 多维比较 | 控制格数、选中重点；移动端可读 |
| 18 空间/路线图 | 位置/路径 | 地名与路径正确；不泄露私人位置 |
| 19 放大镜/聚光 | 引导注意 | 被强调区清楚，周围提供上下文 |
| 20 批注笔迹 | 解释/纠错 | 圈、箭头、下划线；不遮住关键字 |
| 21 代码/终端片段 | 技术证据 | 只显必要行、语法层级；不用假执行日志 |
| 22 字幕/下三分之一 | 旁白与身份 | 实际语音对齐、保留安全区 |
| 23 章节进度 | 长内容导航 | 细小而可辨、位置稳定；不抢主视觉 |
| 24 结尾/行动页 | 收束与下一步 | 一条清楚行动，品牌与联系信息核实 |

## 组合配方

- 产品：宣言标题 → 真实 UI 聚焦 → 前后对照 → 证据/指标 → 结尾。不能只有卖点文字而不见产品。
- 知识：疑问/现象 → 因果链/分解图 → 实例窗口 → 对照总结。旁白驱动同步，不套广告快闪。
- 文化：编辑引语 → 图像/纸墨 → 时间线/细节 → 留白收束。字体与材质节制。
- 数据：问题 → 基线/单位 → 逐步显现图表 → 对照证据 → 可解释结论。趋势不是装饰曲线。
- 口播：人物为主、字幕稳定，仅在概念与证据处插入组件；避免全片用大标题遮人。

## 实现契约

每个复用组件说明输入、内容最大密度、横竖屏布局、进场/稳定/退场、字体与素材依赖、可编辑参数、空值回退和许可。超过可读容量时拆镜头；真实缺图不要用无关网图代替事实。复用者必须看中间状态，不只是起止截图。
